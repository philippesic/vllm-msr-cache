# Observer-only V2 preemption readmission revision

The first frozen campaign contains 1,295 strict physical proofs for 1,296 successful requests. The candidate agent seed 1103 has one invalid proof and remains correctness-ineligible. The old orchestrator incorrectly checked schema/timing validity without requiring all physical proofs; all 24 runs are preserved, including runs executed after that failure. This is an orchestration failure, not an acceptance waiver.

Pinned vLLM V2 emits a preempted request's complete block table in scheduled_new_reqs. The old observer interpreted a second new-request table as invalid even after an actual preemption. The new common hook handles only this boundary: it requires the actual scheduler output, same live request object, observed preemption episode and native preemption count, exact prompt/token/digest identity, complete current native physical table, owned pages and computed-page hashes, and scheduler-owned native key chain. It then delegates to the existing strict full-table replacement validator. It never changes native scheduling, KV, transfers, policies, scoring, budget or workload.

The first 640-block public correctness qualification failed and is retained. Its fixture used serialized event keys instead of live native scheduler keys; the revised tests obtain keys through the actual connector helper. An optional local-prefix snapshot audit was also invoked without configured snapshot IDs; the new diagnostic guard reports not_configured_not_run rather than claiming that audit passed. All-page D2H/H2D transfer auditing remains enabled. Separate prior dedicated local-prefix audits remain separate evidence.

The tiny 640-block pool is correctness stress only. Its timings are excluded. Qualification requires an actual observed native preemption and all strict request proofs plus actual transfer-byte equality. A failed qualification does not qualify the revision. If qualified, the new 12-run agent cohort uses the same frozen traffic, sources, math, policies and budgets, with the same observer in all four arms. Old valid chat results retain their old observer provenance.
