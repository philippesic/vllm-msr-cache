# Issue and failure analysis

This records what went wrong in the old vLLM cache repo and its threads, with evidence, root cause where known, and the rule, check, or plan item that now addresses it. Unaddressed items are marked as such. It is an analysis document, not a status diary and not permission to start a later port stage.

## What already held

The 3 November 2026 structural fixes in the old repo — pinned launcher, four bench tiers, validators, and a light CI check — held, unlike prose-only STATUS rules. Integrity guards kept unfavorable results. Those lessons are carried into the one check command and FINDINGS in this repository.
